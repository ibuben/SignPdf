# Подпись PDF через E-IMZO

Windows-приложение для **локальной** подписи PDF и проверки уже стоящих в файле цифровых подписей. Закрытый ключ приложение не читает: пароль и криптографию берёт на себя установленный клиент **E-IMZO**.

Готовый `SignPdf.exe` портативный: копируете файл на другой компьютер и запускаете. .NET ставить не нужно.

## Что нужно

1. Windows 10 (1809+) / 11 x64.
2. Установленный и запущенный [E-IMZO](https://e-imzo.uz) (`E-IMZO.exe`).
3. Ключ ЭЦП в формате PFX (обычно `C:\DSKEYS`).
4. Для сборки из исходников — [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Если E-IMZO не запущен, приложение покажет ошибку. Пароль ключа вводится **только** в окне E-IMZO.

## Сборка и запуск

```powershell
dotnet run --project src/SignPdf.App -c Release
```

Самодостаточный exe (один файл, без рядом лежащих DLL):

```powershell
dotnet publish src/SignPdf.App -c Release -r win-x64 --self-contained true -o publish
```

Результат: `publish\SignPdf.exe`.

## Как подписывается PDF

1. Приложение подключается к CAPIWS (`ws://127.0.0.1:64646` или `wss://127.0.0.1:64443`).
2. Берёт список PFX-сертификатов через `pfx.list_all_certificates`.
3. iText резервирует `/ByteRange` в PDF.
4. Байты документа (не «голый» хеш) уходят в `pkcs7.create_pkcs7` как detached PKCS#7.
5. CMS встраивается в PDF с `SubFilter = adbe.pkcs7.detached`.

Исходный файл не перезаписывается: сохраняется `имя_signed.pdf`.

## Проверка подписи

Вкладка «Проверить» сначала просит локальный E-IMZO разобрать detached PKCS#7 (`get_pkcs7_detached_info`) — так проверяются ключи O'zDSt / GOST, которые iText и Adobe Reader не понимают. Если E-IMZO недоступен, остаётся разбор CMS через iText/BouncyCastle.

Это **криптопроверка файла**, не онлайн-статус сертификата в реестре PKI Узбекистана (для этого нужен отдельный E-IMZO-SERVER).

Статусы: действительна, документ изменён, сертификат истёк, алгоритм не разобран.

## Ограничения

- Ключи E-IMZO используют **O'zDSt 1092 / GOST** (`1.2.860.3.15.1.3.2.1`). Adobe Reader такие подписи обычно не подтверждает. Это приложение проверяет их через локальный E-IMZO.
- Первая версия работает с **PFX**. ID-карта, BAIK и CKC пока не подключены.
- Нет TSA-метки времени и нет запроса статуса сертификата в реестр.

## Структура

- `src/SignPdf.App` — WPF-окно
- `src/SignPdf.Eimzo` — клиент CAPIWS
- `src/SignPdf.Pdf` — подпись и проверка PDF
